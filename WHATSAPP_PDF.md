# WhatsApp PDF sharing

The **WhatsApp PDF** button now creates a PDF from the same invoice that is shown/printed and uses the device's native Web Share sheet when supported.

On Android/iPhone mobile browsers that support file sharing:
1. Generate the bill.
2. Tap **WhatsApp PDF**.
3. Select WhatsApp in the share sheet.
4. Select the customer/chat.
5. The same invoice PDF is attached to the message.

If file sharing is not supported by the browser, the app downloads the PDF instead and asks you to attach it in WhatsApp manually.

For a fully automatic server-to-WhatsApp send without the share sheet, WhatsApp Business Cloud API integration is required.
